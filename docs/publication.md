# Copyright and publication scope

This repository contains the original RetViM implementation and model metadata. It does not redistribute the accepted manuscript, publisher-formatted paper, paper figures, dataset images, or archived prototype graphics. Historical notebooks and the local demo remain outside this code package.

IEEE's [conference reproducibility guidance](https://conferences.ieeeauthorcenter.ieee.org/write-your-paper/research-reproducibility/) encourages sharing research code and other research outputs. Its [conference paper posting policy](https://conferences.ieeeauthorcenter.ieee.org/author-ethics/guidelines-and-policies/post-publication-policies/) separately defines rules for preprints, accepted manuscripts, and the version of record. This repository uses a short original project description and citation rather than posting the article.

The paper is accepted for presentation at IEEE GSCon 2027. DOI and final proceedings metadata will be added when available. Acceptance is not described as completed proceedings publication.

The code license does not grant rights to the article, third-party software, or model weights. IEEE's cited policies do not specifically resolve the licensing of trained weights; their license remains pending. This packaging decision does not replace the authors' signed publishing agreement or applicable ownership terms.
